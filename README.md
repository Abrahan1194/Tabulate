# Tabulate
README
Descripción

Este script en Python gestiona una lista de usuarios, organizando y visualizando sus datos de contacto, perfil y preferencias. Utiliza la librería tabulate para mostrar la información de manera estructurada en formato de tabla.
Características

    Datos de los usuarios: La información incluye nombre, apellido, correo, teléfono, dirección, fecha de nacimiento, género, ocupación, redes sociales, preferencias de idioma, suscripción a boletín y temas de interés.

    Formato de salida: Se genera una tabla que organiza estos datos, facilitando su visualización de manera clara y ordenada.

Dependencias

Este script requiere la librería tabulate para la presentación de datos. Para instalarla, puedes usar:

pip install tabulate

Uso

El script procesa un diccionario con información sobre los usuarios y luego muestra una tabla con los siguientes encabezados:

    Nombre

    Apellido

    Correo

    Teléfono

    Dirección

    Fecha de Nacimiento

    Género

    Ocupación

    Redes Sociales

    Idioma

    Newsletter (Si está suscrito a boletines)

    Temas de Interés (Temas que le interesan al usuario)
